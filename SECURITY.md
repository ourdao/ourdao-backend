# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us through coordinated disclosure.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please use GitHub's private vulnerability reporting feature:

1. Go to the [Security tab](https://github.com/ourdao/ourdao-backend/security) of this repository
2. Click on "Report a vulnerability" in the top right
3. Provide a detailed description of the vulnerability

Alternatively, you can report vulnerabilities via email to: security@ourdao.io

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |
